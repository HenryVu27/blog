The Problem

Agent Failures Are
Context Failures

The model can do what you need. It just doesn't have the right information when it needs it.

Context windows went from 4K to 200K tokens. Models got intelligent enough that phrasing stopped being the bottleneck. The challenge shifted from "how do I word this instruction" to "what information does the model need to see right now, and how do I assemble it reliably."

Prompt engineering is one technique within context engineering. And context engineering is where most of the actual engineering happens.

NVIDIA's RULER benchmark: fewer than half of models maintained quality at 32K tokens, despite claiming 128K+
The Framework

Seven Components

  • System prompt 500 - 2,000
  • User prompt variable
  • Conversation history 500 - 5,000
  • Long-term memory variable
  • Retrieved knowledge (RAG) 0 - 10,000
  • Tool definitions 500 - 3,000
  • Output schemas 50 - 500
All seven compete for the same finite token budget. Every token should earn its place.
Management Strategies

Write / Select /
Compress / Isolate

Write
Move information out of the window into external storage
Scratchpads, todo files, structured state stores
Select
Retrieve only what's relevant back into the window
RAG, memory queries, tool-description search
Compress
Reduce tokens while preserving task performance
Tiered: raw → compact → summarize. Trigger at 80-90% capacity.
Isolate
Split work across separate LLM calls with focused context
Sub-agents, safety gates, domain-specific windows
Most teams over-invest in writing and selecting. The real gains are in compression and isolation.
When Things Break

Four Failure Modes

  • Poisoning
    A hallucination enters the context and gets treated as ground truth. Errors compound over time.
    Fix: validate before memory writes
  • Distraction
    Context grows so long that the model over-focuses on history and neglects what it learned during training.
    Fix: aggressive trimming + the 80-90% pre-rot threshold
  • Confusion
    Superfluous information gets treated as signal. The model can't distinguish noise from relevant data.
    Fix: curate ruthlessly, every token earns its place
  • Clash
    New information conflicts with existing instructions. Contradictions produce unpredictable behavior.
    Fix: clear precedence hierarchy, audit regularly
Different failures need different fixes. "The agent is broken" is never specific enough.
From My Own Audit

Two Bugs Hiding
in Plain Sight

Bug 1
KV-Cache Violation
Volatile state (turn count, timestamp) prepended to the system prompt. Every turn invalidated the entire cache prefix.
Fix: move volatile state to the end. Three lines of code.
Bug 2
Prompt-Tool Clash
System prompt said "use the data already in context." But the tool's existence signaled the data might not be there. The agent fetched it anyway.
Fix: remove the redundant tool.
